# Clase 4: Componentes Clave de un Sistema de IA

**Sección:** Teoría
**Fecha:** 2026-03-22

## Objetivos
- Identificar los componentes principales de un sistema de IA.
- Comprender el flujo de datos y procesamiento en IA.
- Relacionar estos componentes con los LLMs.

---

### 1. Componentes de un sistema de IA
- **Datos:** Materia prima para entrenar y validar modelos.
- **Modelo:** Algoritmo o red neuronal que aprende patrones a partir de los datos.
- **Entrenamiento:** Proceso de ajuste de parámetros del modelo usando datos.
- **Evaluación:** Medición del desempeño del modelo (precisión, recall, etc.).
- **Inferencia:** Uso del modelo entrenado para hacer predicciones o generar resultados.
- **Despliegue:** Integración del modelo en aplicaciones reales.

### 2. Flujo típico en IA
1. Recolección y preparación de datos
2. Entrenamiento del modelo
3. Evaluación y ajuste
4. Despliegue e inferencia

### 3. Relación con los LLMs
- Los LLMs siguen este flujo: se entrenan con grandes corpus de texto, se evalúan y luego se integran en aplicaciones como chatbots o asistentes.
