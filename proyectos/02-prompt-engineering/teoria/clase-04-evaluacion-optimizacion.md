# Clase 4: Evaluación y Optimización de Prompts

**Sección:** Teoría
**Fecha:** 2026-03-23

## Objetivos
- Aprender a evaluar la efectividad de un prompt.
- Conocer métricas y métodos de optimización.
- Iterar y mejorar prompts para obtener mejores resultados.

---

### 1. Evaluación de prompts
- Analiza la calidad y relevancia de las respuestas generadas.
- Usa criterios como precisión, coherencia, creatividad y cumplimiento de instrucciones.
- Solicita feedback de usuarios o expertos si es posible.

### 2. Métodos de optimización
- Ajusta la redacción y el nivel de detalle del prompt.
- Prueba diferentes estructuras y ejemplos.
- Utiliza técnicas como prompt chaining o few-shot learning.

### 3. Iteración y mejora continua
- Documenta los cambios y resultados.
- Compara versiones de prompts para identificar mejoras.
- Mantén un ciclo de prueba y ajuste constante.
