# Clase 2: Tipos de Prompts y Estructuras Básicas

**Sección:** Teoría
**Fecha:** 2026-03-23

## Objetivos
- Conocer los principales tipos de prompts utilizados con LLMs.
- Aprender a estructurar prompts simples y compuestos.
- Identificar ventajas y limitaciones de cada tipo.

---

### 1. Tipos de prompts
- **Prompts directos:** Instrucciones simples y claras (ej: "Resume el siguiente texto...").
- **Prompts de contexto:** Incluyen información adicional relevante para guiar la respuesta.
- **Prompts de ejemplo (few-shot):** Proveen ejemplos de entrada y salida para mostrar el formato esperado.
- **Prompts encadenados (chain-of-thought):** Guían al modelo paso a paso para tareas complejas.

### 2. Estructura básica de un prompt
- Instrucción clara
- Contexto (opcional)
- Ejemplo(s) (opcional)
- Formato de respuesta esperado

### 3. Ventajas y limitaciones
- Prompts simples: rápidos, pero menos control.
- Prompts con contexto o ejemplos: mayor precisión, pero requieren más diseño.
